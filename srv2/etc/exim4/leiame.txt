File conf.d/acl/30_exim4-config_check_rcpt call inexistant script spfquery.mail-spf-query-perl, resulting in the whole SP framework failing.

Package libmail-spf-query-perl does exist in lenny and sid, but not in testing/squeeze.
There are several packages that provide an alternative, but it looks like /usr/bin/spfquery.mail-spf-perl is the only suitabe:
Package "spfquery" which provides spfquery.libspf2 will not do, as it uses incompatible return codes (example: pass=2 where we expect pass=0)
Package spf-tools-python provides spfquery.pyspf, but the result is returned the stdout, not in the process return code.

So please, call /usr/bin/spfquery.mail-spf-perl rather than inexistant spfquery.mail-spf-query-perl.

Please also note that package exim4-base suggests inexistant package libmail-spf-query-perl. It should suggest package spf-tools-perl instead.
