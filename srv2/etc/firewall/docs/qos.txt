EF (Expedited Forwarding) - Entrega Urgente
RFC 2598 define o processo acelerado de Transmissao (EF) PHB: "O PHB EF podem ser usados ..
 para construir uma baixa perda, baixa latcia, jitter baixos, largura de banda garantida, end-to-end atrav 
 de servis DS (Diffserv) Tais domios servi aparece. para os pontos finais, como uma conex ponto-a-ponto ou uma 
 "linha virtual alugadas." Este servi tamb tem sido descrito como um servi premium. 
 "Codepoint 101110 recomendado para o PHB EF, o que corresponde a um valor DSCP de 46.

Encaminhamento Assegurado
 RFC 2597 define o encaminhamento assegurado (AF) PHB e descreve-o como um meio para um domio DS provedor oferecer 
 diferentes niveis de garantias de encaminhamento para pacotes IP recebidos de um cliente de domio DS. 
 O Assured Forwarding PHB garante uma certa quantidade de largura de banda para uma classe de AF e permite o acesso 
 largura de banda extra, se disponel. Existem quatro classes AF, AF1x atraves AF4x. 
 Dentro de cada classe, htr probabilidades de queda. Dependendo da polica de uma determinada rede, 
 os pacotes podem ser selecionados para um PHB com base no rendimento exigido, delay, jitter, perda ou acordo com a 
 prioridade de acesso aos servis de rede.

 Classes 1-4 sao referidos como classes AF.
  A tabela a seguir ilustra a codificao DSCP para especificar a classe AF com a probabilidade. 
  Bits DS5, DS4 e DS3 definir a classe; perdas DS2 e DS1 especificar a probabilidade de queda; DS0 bit sempre zero.


PPPDDD -> PPP: Prioridade na Entrega: quanto maior melhor - 111 urgente , 000 sem urgencia
       -> DDD: Possibilidade de Drop: quanto menor melhor - 000 sem drop, 111 muitos drops

       -> D:   Possibilidade de Drop (idem acima). 1 (menos drop) ao 3 (mais drop)

        >> Usar CS6 e CS7 para servicos extremamente urgente
